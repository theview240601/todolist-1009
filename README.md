# 내 업무 할 일

내 컴퓨터에서 나 혼자 쓰는 업무·프로젝트용 할 일 목록이에요.
설치할 것도, 서버도 없어요.

## 여는 방법

1. 이 폴더에서 `index.html` 파일을 **더블클릭**해요.
2. 크롬이나 엣지 같은 브라우저에서 바로 열려요.
3. 자주 쓴다면 열린 화면을 **즐겨찾기(Ctrl + D)** 해 두면 편해요.

## 쓰는 방법

- **할 일 추가**: 맨 위 칸에 할 일을 적고 엔터(또는 "추가" 버튼). 프로젝트·마감일·중요도·메모는 골라서 넣어요.
- **완료**: 할 일 왼쪽 네모를 체크하면 줄이 그어지고 목록 아래로 내려가요.
- **수정**: 연필 버튼 → 위 칸에 내용이 채워지면 고치고 "저장". 그만두려면 "취소" 또는 Esc.
- **삭제**: 휴지통 버튼 → "지울까요?"에서 확인.
- **프로젝트**: 왼쪽 칸 아래에서 새 프로젝트를 만들어요. 프로젝트 이름 위에 마우스를 올리면 이름 바꾸기·삭제 버튼이 나와요.
  - 프로젝트를 지우면 그 안의 할 일도 같이 지워져요.
  - 프로젝트는 최소 1개는 남아 있어야 해요.
- **보기 옵션**: 검색(제목·메모), 전체 보기/할 일만/완료만, 마감일·중요도·최근 추가 순 정렬.
- **완료한 일 지우기**: 지금 보고 있는 프로젝트의 완료된 일을 한 번에 지워요.

## 마감일 표시

| 표시 | 뜻 |
|---|---|
| `D-5` | 마감까지 5일 남음 (3일 이하면 주황색) |
| `오늘 마감` | 오늘이 마감일 (주황색) |
| `2일 지남` | 마감이 지났음 (빨간색) |

## 저장에 대해 꼭 알아 둘 점

- 목록은 **브라우저 안(localStorage)** 에 저장돼요. 새로고침하거나 브라우저를 껐다 켜도 남아 있어요.
- 다른 브라우저(예: 크롬 ↔ 엣지)에서 열면 목록이 따로따로예요. **늘 같은 브라우저로** 여세요.
- 브라우저 설정에서 "인터넷 사용 기록 삭제"로 **쿠키 및 사이트 데이터**를 지우면 목록도 지워져요.

## 폴더 구성

```
todolist-1009
├─ index.html        화면 뼈대 (더블클릭해서 여는 파일)
├─ style.css         디자인
├─ js/               동작 코드 — index.html이 이 순서대로 불러와요
│   ├─ storage.js     1. 저장하고 불러오기
│   ├─ dates.js       2. D-day, 마감 지남 계산
│   ├─ render.js      3. 화면에 그리기, 정렬·검색
│   ├─ actions.js     4. 추가·수정·삭제, 프로젝트 관리
│   └─ main.js        5. 버튼 연결, 앱 시작
├─ tests/
│   └─ test.html      자동 검사 페이지
├─ docs/
│   ├─ 계획서.md       지금까지 세운 계획 모음
│   └─ 되돌리기.md     바꿨다가 예전 모습으로 돌아가는 법
└─ README.md         이 설명서
```

## 검사하는 방법

`tests` 폴더의 `test.html`을 **더블클릭**하면 앱의 계산이 맞는지 자동으로 검사해요.

- 맨 위에 **✅ 모두 통과**가 나오면 괜찮은 거예요.
- **❌** 가 보이면 어디가 틀렸는지 빨간 글씨로 알려 줘요.
- 검사는 실제 할 일 목록을 건드리지 않아요.
