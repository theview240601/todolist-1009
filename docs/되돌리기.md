# 바꿨다가 되돌리는 법

디자인이나 기능을 바꿨는데 마음에 안 들 때, 예전 모습으로 돌아가는 방법이에요.

> 💡 명령어를 직접 칠 필요는 없어요. Claude에게 "원본으로 돌려줘", "합쳐줘"라고만 말해도 돼요.

## 원리: 게임 세이브처럼

| 비유 | Git 용어 | 뜻 |
|---|---|---|
| 💾 세이브 파일 | 태그(tag) | 어떤 순간의 모습에 이름표를 붙여 둔 것. 언제든 그 모습으로 돌아갈 수 있어요. |
| 📒 연습장 | 브랜치(branch) | 원본은 그대로 두고 따로 그려 보는 공책. 마음에 들면 원본에 합쳐요. |
| 📗 원본 | `main` 브랜치 | 진짜로 쓰는 버전이에요. |

**할 일 목록은 안전해요.** 할 일은 브라우저 저장소에 따로 있어서, 파일을 바꾸거나 되돌려도 그대로 남아요.

## 지금 있는 세이브 파일

| 이름 | 어떤 모습 |
|---|---|
| `white-design` | 처음 만든 깔끔한 흰 화면 디자인 |

## 상황별 방법

### 1. 새로 무언가를 바꿔 보고 싶을 때 → 연습장 만들기
```bash
git switch -c 연습장이름
```
이제부터 바꾸는 건 연습장에만 기록돼요.

### 2. 연습장 결과가 마음에 들 때 → 원본에 합치기
```bash
git switch main
```
```bash
git merge 연습장이름
```
```bash
git push
```

### 3. 연습장 결과가 마음에 안 들 때 → 원본으로 돌아가기
```bash
git switch main
```
원본 공책을 펴는 것뿐이라, 바로 예전 모습으로 돌아가요.

### 4. 합쳤는데 나중에 후회될 때 → 세이브 파일 불러오기
Claude에게 **"흰 디자인으로 돌려줘"** 라고 말하세요.

세이브 파일(`white-design`)은 폴더 정리 **전**에 찍었어요. 그때는 동작 코드가 `app.js` 한 파일이었지만, 지금은 `js` 폴더로 나뉘어 있어요. 그래서 예전 파일을 그대로 꺼내면 앱이 깨져요. 디자인 파일(`style.css`)만 꺼내고 `index.html`의 장식 부분을 손봐야 해서, 명령 하나로는 안 되고 Claude가 맞춰 줘야 해요.

## 지금 어느 공책을 펴고 있는지 보기
```bash
git branch
```
앞에 `*`가 붙은 게 지금 펴져 있는 공책이에요. 폴더 안의 파일은 **지금 펴진 공책의 내용**으로 보여요.
